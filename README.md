One sentence: the pitch for the worst, most useless app imaginable.

`main.py` (pure Python stdlib, no third-party packages) writes the
pitch to `/output/entry.txt` — 180 characters, one sentence, one
idea, deadpan founder voice:

> ChairSense is a $9.99/month app for people who sit that monitors, in real time, whether the chair you are sitting on is still a chair, and alerts you the moment it stops being one.

## Run it

```sh
python3 main.py
```
